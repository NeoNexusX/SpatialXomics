# SXO-Harness 助手

SXO-Harness 是 SpatialXomics 内置的对话式数据分析助手。它在浏览器中运行，可以围绕当前打开的数据集回答问题：读取离子图、统计、注释、聚类和页面选择，调用化合物、通路、文献与联网检索工具，并把外部来源渲染成引用卡片。

助手只读取现有数据与结果，不会启动预处理、修改注释或重新聚类；这些操作仍需在[数据集分析](./dataset-analysis)和[数据可视化](./data-visualization)中完成。

## 打开面板

登录后，在右下角显示导航球的页面（首页、数据集可视化页等）展开导航球，点击 SXO 图标即可打开面板。导航栏形态的页面目前没有助手入口，请回到首页或数据集可视化页使用。

面板可以拖动标题栏移动、拖拽边缘缩放，点右上角关闭。关闭面板不会删除已保存的对话。

## 首次配置连接

没有可用连接时，面板会直接打开「连接」设置页。助手目前只支持 Anthropic Messages 协议（`/v1/messages`）的端点，OpenAI Chat Completions 等其他协议的端点不能直接使用。

### 地址与密钥

- **API 地址**：填写提供 `/v1/messages` 的端点，例如 `https://api.anthropic.com` 或中转站地址。末尾的 `/v1` 可以省略，误填的 `/messages` 会被去掉；界面会在下方显示实际请求地址。
- **API 密钥**：只保存在当前浏览器的 `localStorage`，不经过平台后端。地址和密钥作为一组生效：只填地址不填密钥不会使用该地址；填了密钥但留空地址时使用该协议的官方地址。
- 部署方也可以预置默认连接（`VITE_LLM_PROXY_URL` / `VITE_LLM_API_KEY` / `VITE_LLM_MODEL`）。已有部署默认时可以直接对话，需要自己的额度时再填写地址和密钥。
- 已保存设置后，左下角出现「清除」；需要连续点击两次（3 秒内）才会清除。

### 选择模型

点击 **获取可用模型** 会读取端点的模型列表，并逐个发送一张小图做多模态测试。助手需要能看图的模型，只有通过测试的模型才能保存和切换。

- 默认只测试前 10 个模型，其余需要点 **继续测试**；可随时 **重新测试**。
- 也可以手动输入模型 ID 后点 **测试**，单独验证某个模型。
- 被判定为不支持图片或不可用的模型不会出现在可保存列表中。
- 保存后进入对话。之后可以在输入框左侧的模型菜单里切换到其他已通过测试的模型，或打开连接设置。

### 上下文上限与会话指令

连接设置底部还有两项：

- **上下文上限**：当前模型可用的上下文窗口，默认 256,000 tokens，可按端点与模型保存，在下一轮生效。
- **会话指令**：导入一个 `.md` / `.txt` 文件（如 `AGENTS.md`，最大 64 KiB），内容会原样加入系统提示词。指令随当前对话保存，只影响这段对话。

## 对话

### 输入与图片

- 按 `Enter` 发送，`Shift + Enter` 换行；输入法组词时的回车只确认候选词，不会发送。
- 点击图片按钮或直接粘贴截图，可以附加 PNG、JPEG、WebP 图片，单条消息最多 4 张；最长边超过 1568 像素的图片会先等比缩小。
- 助手回复支持 Markdown、公式、代码块和工具步骤展示；来源链接会显示为引用卡片，点击在新标签页打开。

### 运行、停止与重试

提交后可以看到思考过程和工具调用步骤。运行中可以停止；最后一条回答可以重试，重新生成会沿用原来的页面选择。

### 上下文用量

输入框右下角的百分比胶囊显示当前上下文占用，点开后可以看到本段对话的输入/输出 token 累计，并可以手动 **压缩上下文**。接近上限时，较早的对话会自动压缩成一条摘要，界面仍保留原文，但模型之后只能看到摘要。

## 数据集上下文

在数据集可视化页打开面板时，助手会自动连接当前数据集。每次提问会记录当时选中的离子、聚类、像素和注释选择，模型据此调用页面工具。若在页面上更换了选中离子、像素或聚类，旧问题不会再使用新的选择；继续提问即可重新捕获。

在首页等没有数据集上下文的页面也可以对话，此时可以使用通用问答、文件与配额查询、化合物/文献检索和联网搜索；依赖数据集页面的工具没有数据可读。

## 可用能力

### 工具

| 类别 | 能做什么 |
| --- | --- |
| 页面与数据 | 读取当前页面状态与选中项、数据集概况、单张或批量离子图（批量最多 9 个 m/z，返回为分图或拼图）、注释行对应的离子图、离子强度统计、平均谱峰、像素谱、KMeans/UMAP 摘要、注释列表与详情 |
| 文件与账号 | 查看公开/个人文件、文件元数据、处理任务和用户配额 |
| 化合物与通路 | PubChem 化合物与分子式检索、ChEBI、HMDB、KEGG 通路、通路富集、本地注释库查询 |
| 文献与网络 | PubMed、Europe PMC、OpenAlex 文献检索，以及 Exa 联网搜索 |
| 会话 | 读取被截断的工具结果存档，按需加载技能说明 |

联网搜索使用 Exa 托管的 MCP，默认走匿名额度；部署方可选配 `VITE_EXA_API_KEY` 提高额度。搜索结果只返回 URL 和摘录，不代表已读全文。

### 技能

空白对话下方提供 **注释审查** 和 **MSI 分析** 两个快捷入口。模型还会按问题自动加载内置技能说明：

- `annotation-review`：审查、比较和排序已有注释
- `msi-analysis`：分析当前数据集、评估数据质量或撰写分析报告
- `ion-image-interpretation`：解读离子图与空间分布
- `adduct-isotope-analysis`：评估加合物与同分子离子证据
- `metabolite-biology`：结合 HMDB、KEGG 和文献解释代谢物
- `literature-evidence`：检索并评估文献证据
- `web-research`：联网检索当前信息与官方文档

## 对话管理

标题栏的对话菜单按数据集保存对话，同一数据集最多保留 3 段。可以切换、新建、删除、导出和导入：

- **导出**生成一个 ZIP，包含对话日志和图片附件；运行中也可以导出。
- **导入**把 ZIP 写入当前数据集，导入前会校验文件完整性和图片引用。
- 对话运行中不能切换、新建或删除，先停止当前回答。
- 同一段对话在另一个标签页打开时为只读，避免两边同时写入。
- 浏览器不支持 OPFS（如部分隐私模式）时会使用临时会话，面板会提示刷新后不再保留。

## 隐私与限制

- 对话、图片和连接密钥保存在当前浏览器；模型请求直接发往你配置的端点。工具会把必要的查询（例如注释、化合物、文献或搜索关键词）发送到对应服务。
- 部署方的 `VITE_LLM_API_KEY`、`VITE_EXA_API_KEY` 会进入浏览器包，只能使用受限的子 key。
- 不要在提问或联网搜索中发送私有样本标识、未公开数据或凭据。
- 模型可能给出错误结论；引用只应来自工具实际返回的来源，但仍建议核对原文和数据库条目。
