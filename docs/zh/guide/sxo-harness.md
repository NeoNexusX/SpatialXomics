# SXO-Harness 助手

SXO-Harness 是 SpatialXomics 内置的对话式数据分析助手。登录后在数据集可视化页等页面打开，即可围绕当前数据集提问：读取离子图、统计、注释、聚类和页面选择，调用化合物、通路、文献与联网检索工具，并把外部来源显示为引用卡片。

助手只读取已有数据和结果，不会启动预处理、修改注释或重新聚类；预处理见[数据集分析](./dataset-analysis)，注释见[数据注释](./data-annotation)，聚类见[可视化工具箱](./visualization-toolbox)。

## 打开面板

登录后，在显示右下角导航球的页面（如数据集可视化页）展开导航球，点击 SXO 图标打开助手。

![SXO 导航球中的助手入口](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20261119160338194.jpg_view)

面板可以拖动标题栏移动、拖拽边缘缩放，点右上角关闭。关闭面板不会删除已保存的对话。

## 首次配置连接

没有可用连接时，面板会直接打开「连接」设置。需要填写三项：**API 地址**、**API 密钥**和**模型**。连接需支持 Anthropic Messages 协议。

<img src="https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20261119160442614.jpg_view" alt="连接设置中的 API 地址、API 密钥和模型字段" style="zoom: 80%;" />

### 地址与密钥

- **API 地址**：填写完整地址，例如 `https://api.deepseek.com/anthropic`。
- **API 密钥**：仅保存在当前浏览器，不经过平台后端。
- 保存后左下角出现「清除」；连续点击两次（3 秒内）才会清除。

### 选择模型

助手只接受多模态模型。保存前，模型需要通过一次图片输入测试：助手发送一张图片，模型需答对颜色。

- **获取可用模型**：读取端点的模型列表，默认测试前 10 个；其余点 **继续测试**，可随时 **重新测试**。
- **手动输入模型 ID**：点 **测试** 只验证当前模型。获取列表返回 404 时使用这种方式。

测试结果有三种：通过的模型进入可保存列表；**不支持图片** 表示端点不接受图片输入；**不可用** 表示测试没有完成，常见原因是密钥、余额、限流、服务端错误或超时。

选中模型后点 **保存**。之后可以在输入框左侧的模型菜单切换到其他已通过测试的模型，或打开连接设置。

### 上下文上限与预设指令

连接设置底部有两项：

- **上下文上限**：按模型的官方文档填写上下文窗口大小，按端点与模型保存，在下一轮生效。未单独设置时使用产品默认值。
- **预设指令**（当前界面名为「会话指令」）：可选，默认不导入。需要自定义助手回答要求时，导入 `.md` 或 `.txt` 文件（最大 64 KiB），内容只对当前对话生效。

### 接入示例：DeepSeek

1. 在 DeepSeek 开放平台创建 API 密钥，并确认账户可用。

   ![DeepSeek 开放平台的 API 密钥页面](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20261119160525696.jpg_view)

2. **API 地址**填 `https://api.deepseek.com/anthropic`。
3. **API 密钥**填第 1 步创建的密钥。同一组地址和密钥下测试过的模型会自动恢复，无需重新测试。
4. 在手动输入框填写模型 ID，例如 `deepseek-flash`，点 **测试**。可用模型以 DeepSeek 官方文档的模型列表为准，所选模型需支持图片输入。
5. 测试通过后，选中模型。在 **上下文上限** 中按模型的官方文档填写，例如官方文档标明上下文为 1M tokens 时，填 `1000000`，再点旁边的 **保存**。

   <img src="https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20261119160734217.jpg_view" alt="已填写 DeepSeek 地址、密钥并选中 deepseek-flash 的连接设置" style="zoom:80%;" />

6. 点面板底部的 **保存**，进入对话。
7. 开始提问。

   <img src="https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20261119161017989.jpg_view" alt="选中 deepseek-flash 后的 SXO-Harness 对话界面" style="zoom:80%;" />

连接失败时，可按报错中的 HTTP 状态排查：

| 表现 | 含义 | 处理 |
| --- | --- | --- |
| 对话报「密钥无效（HTTP 401）」；手动测试显示「不可用」 | 密钥错误、已删除或没有权限 | 重新创建密钥后再测试 |
| 对话报「额度已用完」；手动测试显示「不可用」 | 账户余额不足 | 充值后再测试 |
| 对话提示“地址或模型不存在（HTTP 404）” | API 地址或模型 ID 不正确 | 检查 API 地址是否为 `https://api.deepseek.com/anthropic`，并核对模型 ID |
| 获取模型列表返回 HTTP 404 | 端点未提供模型列表接口 | 改用手动输入模型 ID，再点击 **测试** |
| 对话报「请求过多或配额已用完（HTTP 429）」 | 触发限流 | 稍后重试 |
| 手动测试显示「不可用」，且没有上面的报错 | 服务端错误、网络问题或测试超时 | 稍后重新测试；仍失败时检查本机网络与代理 |

## 对话

### 输入与图片

- 按 `Enter` 发送，`Shift + Enter` 换行；输入法组词时的回车只确认候选词，不会发送。
- 点击图片按钮或直接粘贴截图，可以附加 PNG、JPEG、WebP 图片，单条消息最多 4 张；最长边超过 1568 像素的图片会先等比缩小。
- 回复支持 Markdown、公式、代码块和工具步骤展示；来源链接会显示为引用卡片，点击在新标签页打开。

### 运行、停止与重试

提交后可以看到思考过程和工具调用步骤。运行中可以停止；最后一条回答可以重试，重新生成会沿用原来的页面选择。

### 上下文用量

输入框右下角的百分比胶囊显示当前上下文占用。点开后可以看到本段对话的输入/输出 token 累计，并可以手动 **压缩上下文**。接近上限时，较早的对话会自动压缩成一条摘要，界面仍保留原文，但模型之后只能看到摘要。

## 数据集上下文

在数据集可视化页打开面板时，助手会自动连接当前数据集。每次提问会记录当时选中的离子、聚类、像素和注释选择，模型据此调用页面工具。若在页面上更换了选中离子、像素或聚类，旧问题不会再使用新的选择；继续提问即可重新捕获。

在没有数据集上下文的页面打开面板时，也可以进行通用问答、文件与配额查询、化合物/文献检索和联网搜索；依赖数据集页面的工具没有数据可读。

## 可用能力

### 工具

| 类别 | 能做什么 |
| --- | --- |
| 页面与数据 | 读取当前页面状态与选中项、数据集概况、单张或批量离子图（批量最多 9 个 m/z，返回为分图或拼图）、注释行对应的离子图、离子强度统计、平均谱峰、像素谱、KMeans/UMAP 摘要、注释列表与详情 |
| 文件与账号 | 查看公开/个人文件、文件元数据、处理任务和用户配额 |
| 化合物与通路 | PubChem 化合物与分子式检索、ChEBI、HMDB、KEGG 通路详情与成员化合物查询，并可取回 KEGG 通路图；脂质候选通过注释面板生成后读取 |
| 文献与网络 | Europe PMC、PubMed 文献检索，按论断自拟关键词；两者都不可用时改用联网搜索 |

联网搜索返回网页链接和摘要，不读取全文。

### 技能

空白对话下方提供 **注释审查** 和 **MSI 分析** 两个快捷入口。对话中，助手会根据问题自动选用相应的分析流程，例如离子图解读、加合物与同位素判断、代谢物生物学解释和文献证据检索。

## 对话管理

标题栏的对话菜单按数据集保存对话，同一数据集最多保留 3 段。可以切换、新建、删除、导出和导入：

- **导出**生成一个 ZIP，包含对话日志和图片附件；运行中也可以导出。
- **导入**把 ZIP 写入当前数据集，导入前会校验文件完整性和图片引用。
- 对话运行中不能切换、新建或删除，先停止当前回答。
- 同一段对话在另一个标签页打开时为只读，避免两边同时写入。
- 浏览器不支持所需的本地存储能力（如部分隐私模式）时会使用临时会话，面板会提示刷新后不再保留。

## 数据与保存

对话、图片和连接密钥保存在当前浏览器；模型请求直接发往你配置的端点。工具会把必要的查询（例如注释、化合物、文献或搜索关键词）发送到对应服务。
