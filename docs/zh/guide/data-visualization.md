# 数据可视化

本文介绍SpatialXomics中数据集离子图、TIC 图与质谱图的查看方式，涵盖 UMAP/KMeans 聚类、ROI 圈选、区域比较与注释匹配等空间分析操作。

作者：陈柯江

问题反馈：如果在使用 SpatialXomics 或阅读文档时发现问题，可通过 [GitHub Issue](https://github.com/NeoNexusX/MassVision/issues) 提交反馈，或联系邮箱：**jydong@xmu.edu.cn**。



## 操作说明

### 1. 数据集状态区分

数据集封面主要会呈现两种形式：“Explore” 和 “Visualize”。

![image-20260909211924082](https://cdn.neonexus.top/docs/20260909211924161.jpg_view)

当数据集处在”Explore“时，此时数据集还在待处理阶段，还无法查看可视化结果，需点击`Explore`后再选择`Generate`创建数据预处理任务，创建成功后，将自动跳转至Workspace页面，页面具体信息见[工作区](./workspace)。

![image-20260909212549202](https://cdn.neonexus.top/docs/20260909212549240.jpg_view)

当数据集处在“Visualize”时，此时数据集已经过预处理，点击`Visualize`即可跳转至数据可视化页面，直接查看可视化结果。



### 2. 可视化页面简介

可视化页面可主要分为离子强度图、像素谱图、区域比较栏、基本信息栏、注释面板五个功能模块。后文将对以上五个模块功能详细介绍。

![image-20260911150203224](https://cdn.neonexus.top/docs/20260911150203309.jpg_view)

#### 2.1 基本信息栏

**1.Info（信息）**

显示数据集元数据：Polarity（极性）、Analyzer（质量分析器）、Ionisation Source（离子源）、Pixel Size（像素尺寸）、Resolving Power（分辨率）、Matrix（基质）、Matrix Application（基质涂布方式）、Solvent（溶剂）、Spectrum Mode（谱图模式）、Storage Mode（imzml存储模式）。

下方的 **Biological & Sample Info（生物与样本信息）** 显示上传时填写的样本信息：物种、组织部位、实验条件、培养条件、稳定化处理、组织前处理。

这些信息取自源数据集，预处理后的结果同样会显示；上传时未填写的字段不显示。

**2. Display Range（显示范围）**

- 直接输入 Min/Max 数值
- 实时显示当前值对应的**百分位**（如 "95.23%")

**3. Statistic（统计）**

- **强度直方图**：可视化强度分布，红线标记当前 Min/Max
- **Dimensions**：图像尺寸（如 100 × 80)
- **Non-zero**：非零像素数量
- **TIC**：总离子流

**4. Preprocessing（预处理）**

显示该结果使用的处理方法列表，如 "Direct conversion (no preprocessing)"

**5. Visualization（可视化控件）**

- Gamma 校正：
  - 滑块范围 0.5–1.5，默认 1.0
  - 调整图像亮度/对比度曲线
- UMAP / KMeans 降维聚类（仅 Continuous 模式）

| 功能                   | 说明                                                  |
| ---------------------- | ----------------------------------------------------- |
| **Enable UMAP/KMeans** | 首次开启需确认，后端创建 UMAP 计算任务                |
| **UMAP**               | 显示 UMAP 降维嵌入的二维分布覆盖层                    |
| **KMeans**             | 在 UMAP 基础上做 KMeans 聚类（k=2–20)，本地浏览器计算 |
| **Opacity**            | 分别调节 UMAP/KMeans 覆盖层透明度                     |
| **Export PNG**         | 导出 UMAP/KMeans 图像                                 |
| **Cluster 筛选**       | 勾选/取消特定 cluster，控制显示范围                   |

**6. Region of Interest(ROI)**

| 功能                    | 说明                                       |
| ----------------------- | ------------------------------------------ |
| **Rect**                | 拖拽绘制矩形 ROI                           |
| **Lasso**               | 自由绘制不规则 ROI                         |
| **Confirm/Cancel**      | 确认或取消当前草稿                         |
| **ROI only / Show all** | 切换：只显示 ROI 区域 或 显示完整图像      |
| **ROI 统计**            | 每个 ROI 显示：Pixels、Mean、Std、Min、Max |
| **管理**                | 删除单个 ROI 或 Clear all                  |

**7. Mask Import & Export（掩膜导入/导出）**

可将 ROI 掩膜与 KMeans 聚类结果导出为二值掩膜文件，也可导入掩膜文件作为显示过滤。

| 功能                            | 说明                                                         |
| ------------------------------- | ------------------------------------------------------------ |
| **Format**                      | 选择掩膜文件格式（.npz / .csv）                              |
| **ROI masks / KMeans clusters** | 勾选要包含的区域，勾选的多个区域会合并为一个二值掩膜         |
| **Export mask**                 | 导出一个掩膜文件，文件内嵌数据集名称、形状、像素尺寸与像素数据的 SHA-256 校验值 |
| **Import mask**                 | 导入掩膜文件并作为离子图的显示过滤                           |
| **Apply Mask / Show Original**  | 重新应用已导入的掩膜，或暂停掩膜显示完整图像（导入掩膜后出现） |
| **Clear imported mask**         | 清除已导入的掩膜                                             |

**1.图像交互**

| **缩放**     | 鼠标滚轮在离子图区域以指针位置为中心缩放；右下 `− / 倍率 / +` 按钮 |
| **平移**     | 放大后按住左键拖动                                           |

- **Display Range 滑块**：拖动调整 Min/Max，改变对比度
- **Gamma 校正**：右侧滑块，范围 0.5–1.5，默认 1.0

**4. 多离子叠加**

Continuous 数据可将多个离子同时叠加为多个颜色通道显示。开启`Overlay mode`后，可将当前 m/z 添加为一个通道；也可使用`Batch add m/z`，直接在谱图上点击峰批量添加。

- 最多支持 **10 个通道**，每个通道按各自的强度范围独立归一化后叠加为不同颜色；
- 每个通道可单独控制可见性、颜色与透明度；
- 叠加激活时，Display Range、Colormap 与 Gamma 控件均会置灰（叠加渲染不使用这些设置）。

#### 2.4 区域比较

**仅 Centroid 数据可用**，用于比较两个区域（A vs B）的谱图差异。主要有两类数据来源，KMeans 聚类产生的 clusters或用户绘制的 ROIs，现就以上两类数据比较做一流程介绍。

设置最低检出率（Minimum detection rate）与强度阈值（Intensity threshold）后点击`Compare`进行比较。比较时同一组的多个成员先合并（并集），结果分为五类：**仅 A（A only）**、**仅 B（B only）**、**A 富集（A enriched）**、**B 富集（B enriched）**、**共有（Shared）**，并显示两边的检出率与平均强度。

#### 2.5 注释面板

注释面板位于可视化页面左侧，可折叠/展开。选择注释 CSV，点击 **开始注释** 后，面板用峰与库中分子的理论加合离子匹配、打分并估计 FDR，再在后台为排名靠前的注释补算空间分。表格里一行是一个加合离子：同一分子的不同加合离子各占一行，相互关联、可以跳转。

::: warning 前提条件
注释支持对齐后的 **centroid** 数据（continuous 存储），并需要与 m/z 轴对应的平均谱。注释库可以自己提供 CSV，也可以在注释面板直接导入平台的参考数据库（见[数据库](./database)）。
:::

**1. 选择注释库 CSV 与待匹配峰**

点击 **选择注释 CSV** 打开本地文件；**从平台库导入** 下拉则列出平台的参考数据库（见[数据库](./database)），选中后在线拉取整库 CSV（按钮显示下载进度）并导入，与本地文件走同一套解析。两种方式导入的库都只在当前浏览器读取并保存，不上传到服务器；下次打开可以恢复用户此前选择的库，也可以清除或重新选择。

- 库模板为 `ID,Name,Formula,InChI,Mass`，一行一个化合物。`Formula` 必需；`Mass` 为单同位素中性质量（Da），缺失时根据分子式计算，其余列可选。同分子式的异构体合并为多个候选。
- 可选的 `Origin` 列标注化合物来源：`endogenous`（内源）、`expected`（预期内源）、`unknown`（未定）、`exogenous`（外源）。同分子式的候选按这个顺序排列，同级保持文件里的先后，排第一的就是显示名。来源只决定先后和标签，不计入总分，也不影响 q 值；没有这一列时候选按文件顺序排列。
- 编码支持 UTF-8（含 BOM）和 GBK/GB18030，分隔符自动识别。
- 待匹配峰直接来自数据集平均谱，先去掉平均强度为 0 的轴点，再通过滑动条按强度排名去掉最低的 0–99%（默认 0%）。百分比按峰数计算，松手后生效。峰本身就在 m/z 轴上，可以直接读取离子图和跳转。
- 点击 **空间计算** 输入框右侧的 **开始** 按钮后运行。打开面板、重新进入结果页或更换库、峰过滤比例、容差、空间计算比例、评分权重、加合物时都不会自动匹配；条件变化会清除旧结果，需要再次点击按钮。每个结果页只记住设置。

**2. 条件**

条件卡汇总本次注释用到的设置，第一次出结果后自动收起成一行摘要。

- **数据集**：极性、离子源、基质、分析器和溶剂，取自数据集元数据。缺少极性时需要在这里手动选择。
- **容差**：不填时按分析器给默认值（Orbitrap 5 ppm、FTICR 3 ppm、timsTOF/Q-TOF 10 ppm、TOF 20 ppm，分析器未知时 10 ppm）；也可以自己填写，支持 ppm 和 Da。
- **评分权重**：三个输入框依次为 质量 : 加合适配度 : 空间，每项最小 0.1、可以有小数，三项之和须为 10，默认 6 : 1 : 3；总分权重即各项 ÷ 10（默认 0.6 / 0.1 / 0.3）。单项超出 0.1–9.8 的输入不生效，清空某一项恢复它的默认值，旁边的按钮恢复 6 : 1 : 3。三项之和不为 10 时输入框标红，不能开始。修改后点击 **开始** 重新运行，q 值也按新的总分重新估计。
- **加合物**：先按极性筛选，再根据离子源、基质和溶剂中的添加剂给出每种加合物的适配度（0~1），适配度为 0 的不启用。展开多选列表后逐项勾选或取消，自动启用与手动启用保留各自颜色；每行显示适配度，悬停可查看质量位移和条件。

| 加合物 | 默认适配度 | 条件与调整 |
| --- | --- | --- |
| [M+H]⁺ | 1.0 | 所有离子源 |
| [M+Na]⁺ | 0.8 | MALDI/LDI 为 0.9；溶剂含钠盐为 1.0 |
| [M+K]⁺ | 0.6 | MALDI/LDI 为 0.9 |
| [M+NH₄]⁺ | — | 溶剂含铵时为 0.8 |
| [M+Li]⁺ | — | 溶剂含锂时为 0.9 |
| [M+Ag]⁺ | — | 银纳米颗粒基质或溶剂含银盐时为 1.0 |
| [M−H]⁻ | 1.0 | 所有离子源 |
| [M+Cl]⁻ | 0.7 | ESI 类离子源为 0.8；溶剂含氯为 0.9；NEDC 基质为 1.0 |
| [M+HCOO]⁻ | — | 溶剂含甲酸根时为 0.8 |
| [M+CH₃COO]⁻ | — | 溶剂含乙酸根时为 0.8 |

[M+H−H₂O]⁺、[M−H−H₂O]⁻ 等不会自动启用，需要手动开启。

**3. 打分与 FDR**

每一行的总分由三部分加权，权重可在条件的 **评分权重** 中调整（见上），下表为默认值；详情卡的评分明细显示本次运行实际使用的权重：

| 部分 | 默认权重 | 含义 |
| --- | --- | --- |
| 质量 | 0.6 | 质量误差越小越高（误差为 0 时为 1，到容差边缘约 0.14） |
| 加合适配度 | 0.1 | 该加合物与采集条件的匹配程度 |
| 空间 | 0.3 | 0.2 × 空间混乱度 + 0.8 × 同分子共定位（见下） |

FDR 用 target-decoy 方法估计：给每个分子式配上化学上不可能出现的加合物（如 [M+Pt]⁺）作为 decoy，走同样的匹配和打分，得到每行的 q 值，越小越可信。

**4. 空间评分**

后台默认为全部匹配项所在的分子组读取离子图。“条件”中的 **空间计算** 输入框使用百分比，默认 100%；例如 20% 会按初始排名取前 20% 的匹配项（数量向上取整），计算这些项所在分子组的全部离子；0% 不计算空间分。修改后点击右侧 **开始** 按钮运行，按结果页记住设置。计算两部分：

- **空间混乱度**（METASPACE 的 level-set 方法）：离子图分布成块分高，散点噪声分低。计算范围内的行都会计算，不要求有多个加合离子。
- **同分子共定位**：面板计算同一分子各加合离子的离子图之间的 Pearson 相关 r（只比较至少一张图非零的像素），只取严格大于 0.1 的最大相关作为共定位分。r ≤ 0.1 时共定位贡献为 0；悬浮卡片隐藏 r < 0.1 的同分子离子行，筛选后没有离子则隐藏整个小节。空间分 = 0.2 × chaos + 0.8 × coloc；没有其他加合离子或相关无法计算时，共定位按 0 计，因此只有单个加合离子的空间分最高为 0.2。

评分期间分数在行内逐步更新，全部完成后统一重排并更新 q 值，也可以点击 **立即重排**。默认同时计算全部目标与 decoy；限定比例时，decoy 按相同初始总分阈值安排任务。未纳入任务、仍在计算或取图失败的行，空间分按 0 计，不增加总分。

**5. 表格与详情**

- 每行两行字：第一行是名称（+N 表示还有 N 个同分子式的候选名）和 q 值，q 值按档位着色（≤10% 绿、≤20% 黄、其余灰）；第二行是加合物、实测 m/z 与质量误差。悬停 q 值可以看到总分。
- 库里有 `Origin` 列时，名称后的小标签是显示名的来源：内源、预期或外源（未定不显示）。标外源说明这个分子式的候选全部是外源物质。
- 第二行末尾的小标签是同一分子检出的其他加合离子，点击跳到那一行；悬停一行时，同分子的其他行会浅色高亮。叠层图标表示同一峰有多个注释结果。
- 点击一行，离子图切到对应 m/z，谱图同步高亮。
- 悬停一行约 1 秒弹出详情卡（可钉住），从上到下：q 值、总分与排名、质量误差；评分明细表（质量、加合适配、空间，以及空间子项 chaos、共定位的原始分、总分权重和贡献），总分下方紧接实测与理论 m/z（保留 6 位小数）及强度；同分子的其他加合离子及其与当前离子的空间相关 r（行尾的圆箭头按钮跳到那一行），「只看这个分子」按钮位于该小标题旁，使用主色突出显示；同一峰上的其他注释（先按来源、再按排名排列，同样用圆箭头跳转）；候选化合物列表（名称、来源标签和库内编号，HMDB 等常见编号可直接打开数据库页面；可复制 InChI、查询 PubChem）。未算出的空间分及其对总分的贡献均显示 0；chaos 和共定位未计算时显示「–」。
- q 值档位（≤5% / ≤10% / ≤20% / 全部）在表格上方，每档带行数。
- **筛选**：搜索框旁的按钮展开加合物多选列表、只看有同分子离子的行，以及排序（总分（默认）、q 值、空间分、质量误差、m/z、强度、来源（内源在前，同级按排名），可反向）；可以同时勾选多种加合物，清空选择则显示全部；改过的项数会显示在按钮上。搜索支持名称、分子式、m/z；详情卡里还有「只看这个分子」。

点击 **PubChem** 按钮弹出查询窗口，按化合物名检索 PubChem，展示结构式、CID、IUPAC 名称、SMILES 与 InChIKey，可一键复制或跳转 PubChem 页面。

**6. 导出**

点击下载按钮，把当前表格（含筛选与排序）导出为 `<runId>_annotations.csv`：每个离子一行，包含显示名的来源（Origin）、候选化合物与编号、各项分数、q 值、同分子的其他加合离子（含 r）和同一峰上的其他注释。
