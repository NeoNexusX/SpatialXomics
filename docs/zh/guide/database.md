# 数据库

「数据库」页浏览平台内置的参考数据库，入口在顶部导航栏的 **数据库**。浏览需要登录：未登录访问会先跳转登录页，登录后自动返回本页。

## 检索与筛选

工具栏提供关键词搜索和两个筛选条件，所有条件之间取交集。

- **关键词**：点击 **搜索** 或按回车提交。关键词按内容自动选择匹配字段：以 `HMDB` 开头按**编号**检索；形如元素符号加计数的写法（如 `C7H11N3O2`）按**分子式**检索；其余按**名称**检索。一次只匹配一个字段，不做跨字段搜索。
- **来源**：下拉选择内源性 / 预期 / 未知 / 外源性，选择后立即重新检索。
- **质量**：填写最小 / 最大质量（Da）组成闭区间，可只填一边；点击 **搜索** 或回车后生效。质量缺失的行会被质量区间排除。

存在任一条件时，工具栏会出现 **清除** 按钮，一键清空关键词与筛选条件。

## 表格

当前数据源为 **HMDB 4.0 代谢物**。列依次为编号、分子式、名称、InChI、质量、来源、PubChem、HMDB。

- 质量保留 4 位小数，缺失时显示「—」；来源显示为内源性 / 预期 / 未知 / 外源性。

- 名称与 InChI 过长时截断显示，行内复制按钮可复制完整内容。

- **PubChem** 列按化合物名称打开 PubChem 检索弹窗；**HMDB** 列在新窗口打开对应的 HMDB 条目页。

- 底部分页栏可切换页码与每页条数。

## 用作注释库

本库可直接接入[数据可视化](./data-visualization)的注释功能：

- **直接导入**：注释面板的 **从平台库导入** 按钮下拉选择本库，在线拉取整库并完成导入，无需手动下载文件。
- **手动导入**：工具栏右侧的 **下载整库 CSV** 按钮下载完整数据库（约 38.5 MB），文件表头为 `ID,Name,Formula,InChI,Mass,Origin`，与注释库模板一致，可作为注释 CSV 导入。
