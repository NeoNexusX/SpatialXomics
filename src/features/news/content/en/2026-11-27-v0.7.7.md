title: Visualization workbench upgrade; easier collection metadata upkeep
summary: The result page gains a collapsible Toolbox, an intensity strip and fuller ROI editing (combinations, pixel collecting, mask import); zarr data is read from a CDN and downloads use CDN links; collection sample/acquisition fields now offer to follow member changes, with write validation aligned to the backend.
---

## Visualization workbench

- The right sidebar is now a collapsible **Toolbox**; Info, Intensity, clustering, ROI and region-mask sections start collapsed, and the ⓘ icon beside headings and parameters explains them.
- A vertical intensity strip beside the image adjusts Max / Min by dragging its two handles; Gamma and other settings remain in the Intensity block.
- ROI editing is fuller: rectangle, ellipse, polygon and freehand, with Add / Subtract / Intersect combinations and undo/redo; **Collect** picks pixels with signal, without signal, or all acquired pixels; mask files can be imported directly as ROIs.
- KMeans can be limited to the pixels inside a chosen ROI; clustering overlays support opacity and PNG export.
- Region comparison now draws on ROIs and KMeans clusters alike; results are dropped when a region is deleted or a clustering run is repeated.

## Data reading and downloads

- Zarr data on result pages is read from a CDN: faster first loads, and long-lived pages no longer fail when credentials expire.
- Dataset and collection-member downloads now use direct CDN links; the download flow is unchanged, and a temporarily unavailable service shows **Downloads are temporarily unavailable**.

## Collections

- Write validation is aligned with the backend: name up to 128 characters, description 512, title 500, journal 255, citation and abstract 16,000 each; clearing the publication time now saves correctly.
- After members are added or removed, sample and acquisition fields (organism, polarity and so on) that need to follow are listed for confirmation before updating; other values are left untouched.
- Creating a collection or adding members now explains the 300-dataset limit up front, instead of sending a request bound to fail.
