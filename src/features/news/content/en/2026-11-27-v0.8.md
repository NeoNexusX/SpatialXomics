# 🚀 New features and upgrades

## 🤖 SXO Harness Agent framework

The all-new SpatialXomics Agent framework has officially arrived 🎉 Backed by a rich ecosystem of tool plugins and a standardized, extensible way to connect models, it brings an analysis Agent tailor-made for spatial metabolomics.

- **Semantic understanding of spatial metabolomics data.** Automatically gathers an overview of the current dataset, together with the ions, pixels, clusters and other items selected in the workbench, and builds them into a structured context so that multimodal LLMs can accurately read MSI data and answer questions about it.
- **Putative metabolite annotation.** Starting from database annotation results, it weighs mass error, chemical properties, the biological characteristics of the sample, spatial distribution and pathway associations to assess the confidence of each candidate, then recommends which to validate first.
- **Standardized compound search tools.** Query HMDB, PubChem and ChEBI by name or molecular formula to retrieve molecular formulas, exact masses, chemical properties and more. Candidate compounds can also be searched in KEGG by measured m/z and adduct type.
- **Metabolic pathway lookup.** Look up KEGG pathways, pathway maps and their member compounds to link candidate metabolites to known metabolic pathways.
- **Literature evidence search.** Supports PubMed, Europe PMC and web search, and can go online for supplementary material. Every source can be checked through its citation link.
- **Analysis conversation management.** Conversations are saved locally per dataset; third-party LLM APIs are supported; one-click export and import let you pick up your analysis seamlessly, anytime and anywhere.

## 🎨 Visualization workbench

- 🧰 **Workbench Toolbox update.** The right-hand panel is now a collapsible `Toolbox`.

  - **Collapsible sections**: Info, Intensity, Clustering, Region of interest, Region masks and other sections start collapsed and can be expanded as needed.
  - **Parameter help**: a new ⓘ icon next to parameters explains what each one means, right where you need it.

- ✏️ **ROI construction.** Draw freely and combine flexibly to build ROIs of any complexity:

  - **Draw**: rectangle, ellipse, polygon, freehand and Collect tools;
  - **Combine**: Add / Subtract / Intersect Boolean operations with undo / redo — for example, subtract the embedding medium at the edges and keep only the tissue itself;
  - **Collect**: the new Collect tool gathers pixels with signal, without signal, or all acquired pixels;
  - **Import**: import mask files directly as ROIs.

- 📊 **KMeans clustering improvements**:

  - **Scope**: run within a chosen ROI to focus clustering on a local region;
  - **Parameters**: a clearer, more intuitive control for setting k;
  - **Result export**: adjustable opacity, with PNG export.

- **Region comparison update.** ROIs and KMeans cluster regions now serve alike as comparison sources. Deleting a region involved in a comparison, or re-running the related clustering, automatically clears the corresponding comparison results.

## ⚡ CDN acceleration

- Result-page data, as well as dataset and collection-member downloads, are now served from a CDN, with network routes optimized for access from mainland China. After the first load, repeat visits are **over 10× faster**, and loading speeds in mainland China are markedly improved.

# 🐛 Bug fixes

## ⬆️ Compute engine upgrade

- 📈 The dataset size limit has been raised from 20 GB to **100 GB** (measured as the combined size of the imzML and ibd source files). Large datasets that previously could not be uploaded because they exceeded the limit can now be uploaded in one go and submitted directly to the cluster for processing. If a task failed for you in the previous version, we have already notified you by email; simply re-run the task to get your results. If you did not receive the email, please contact jszszzy@foxmail.com or the project lead.

## 📋 Collections

- **Form validation improvements.** Input length limits have been adjusted: name up to 128 characters, description 512, title 500, journal 255, and citation and abstract 16,000 each.
- **Publication date fix.** A publication date that has been filled in can now be cleared and saved normally.
- **Member info sync with confirmation.** After datasets are added or removed, changes to sample and acquisition information such as organism and polarity are listed automatically, and the affected values are updated after confirmation.
- **Member limit notice.** When creating a collection or adding members, selection is limited to at most 300 datasets per collection, with a notice when the limit is exceeded.
