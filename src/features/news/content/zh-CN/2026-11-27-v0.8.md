# 🚀 新功能与升级

## 🤖 SXO Harness Agent 框架

全新 SpatialXomics Agent 框架正式登场 🎉 依托丰富的工具插件生态，加上标准化、可扩展的模型接入方式，为空间代谢组学量身打造专属分析 Agent。

-  **空间代谢组学数据语义理解**。自动获取当前数据集概况，以及工作台中选中的离子、像素、聚类等信息，构建结构化上下文，让多模态 LLM 准确读懂 MSI 数据并回答相关问题。
-  **代谢物注释推定**。基于数据库注释结果，综合质量误差、化学特性、样本生物学特征、空间分布与通路关联，评估候选可信度，给出优先验证建议。
- **标准化合物检索工具**。支持 HMDB、PubChem 和 ChEBI 查询，可按名称或分子式检索化合物，获取分子式、精确质量、化学特性等信息。支持基于实测 m/z 和加合物类型在 KEGG 中检索候选化合物。
- **代谢通路查询**。支持查询 KEGG 通路、通路图及成员化合物，关联候选代谢物与已知代谢通路。
-  **文献证据检索**。支持 PubMed、Europe PMC 及联网检索，并可联网补充资料。通过引用链接即可核查来源。
-  **分析对话管理**。对话内容按数据集保存在本地，兼容第三方 API 接入，支持一键导出与导入，让分析随时随地无缝接续。

## 🎨 可视化工作台

- 🧰 **工作台工具箱更新**。右侧面板改为可折叠的 `Toolbox`。

  - **分区折叠**：Info、Intensity、聚类、ROI、区域掩膜等区块默认收起，可按需展开。
  - **参数说明**：参数旁新增 ⓘ 图标，可就地查看参数含义。

- ✏️ **ROI 区域构建**。绘制自由、组合灵活，可构造任意复杂的 ROI 区域：

  - **绘制**工具：矩形、椭圆、多边形、自由手绘、收集；
  -  **组合**：Add / Subtract / Intersect 布尔运算，支持撤销 / 重做——如扣除边缘包埋区域，仅保留有效组织；
  -  **收集**：新增 Collect 工具，按有信号 / 无信号 / 全部已采集像素收集；
  - **导入**：掩膜文件直接导入为 ROI。

- 📊 **KMeans 聚类优化**：

  -  **范围限定**：可在指定 ROI 内运行，聚焦局部区域聚类；
  - **参数设置**：K 值设置界面更直观清晰；
  - **结果导出**：支持透明度调节，可导出 PNG。

- **区域比较更新**。统一使用 ROI 与 KMeans 聚类区域作为比较来源。删除参与比较的区域或重新运行相关聚类后，自动清除对应的比较结果。

## ⚡ CDN 加速

-  结果页数据及数据集、集合成员的下载已改为从 CDN 读取，并针对大陆地区访问优化链路；首次加载后，再次访问速度提升 **10 倍以上**，大陆地区读取速度显著改善。

# 🐛 Bug 修复

## ⬆️ 计算引擎升级

- 📈 数据集大小上限从 20 GB 提升至 **100 GB**（按 imzML 与 ibd 源文件大小之和计）。此前因超出上限而无法上传的大数据集，现在可一次上传、直接提交集群处理。若您在上一版本中遇到任务运行失败，我们已通过邮件通知；重新运行任务即可获取结果。如果没有收到邮件麻烦联系：jszszzy@foxmail.com 或者联系项目负责人

## 📋 数据集合

-  **表单校验优化**。输入长度限制调整，名称最多 128 字符、简介 512 字符、标题 500 字符、期刊 255 字符，引用与摘要各 16000 字符。
- **发表时间修复**。支持清空已填写的发表时间并正常保存。
-  **成员信息同步确认**。添加或移除数据集后，自动列出物种、极性等样本与采集信息的变化，经确认后更新受影响的取值。
- **成员上限提示**。创建集合或添加成员时，按每个集合最多 300 个数据集限制选择，并在超出上限时提示。
